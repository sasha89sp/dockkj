=======================================================
  AeroDock Portable v2 — Flutter для Windows (GitHub CI)
=======================================================

Полноценная нативная док-панель в стиле RocketDock на Flutter Desktop.
Полностью портативна: все настройки (aerodock-config.json) и извлечённые
значки (папка icons/) хранятся строго рядом с aerodock.exe.

ВКЛЮЧЁННЫЕ ВОЗМОЖНОСТИ:
1. Настоящая прозрачность окна и эффект Acrylic (flutter_acrylic)
2. Автоизвлечение родных иконок .exe/.lnk в icons/ + выбор своих PNG/ICO
3. Встроенные окна «Настройки панели» и «Свойства значка» внутри aerodock.exe
4. Иконка в системном трее, выбор монитора и автозагрузка (shell:startup)
5. Индикаторы запущенных программ Windows и перетаскивание иконок мышью
6. Живые стеки реальных папок Windows (например, Загрузки) и групп ссылок
7. Глобальная клавиша Alt+Space и фирменная иконка aerodock.exe

СБОРКА В ОБЛАКЕ НА GITHUB ACTIONS:
1. Нажмите «Push changes to GitHub» в Google AI Studio.
2. Откройте ваш репозиторий на GitHub -> вкладка Actions ->
   «Build AeroDock Windows Portable».
3. Через ~3 минуты скачайте артефакт AeroDock-Windows-Portable-x64.zip,
   распакуйте в любую папку (или на флешку) и запустите aerodock.exe.
