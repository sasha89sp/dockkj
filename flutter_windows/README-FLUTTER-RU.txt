============================================================
AeroDock Portable v3.5 для Windows (Flutter + Native Win32)
============================================================

Полностью портативный аналог RocketDock с поддержкой 1–3 независимых панелей,
импортом Settings.ini из оригинального RocketDock 1.3.5 и панелью «Разработка»!
Все настройки хранятся в Settings.ini рядом с aerodock.exe (запуск с флешки).

1. ИМПОРТ SETTINGS.INI ИЗ ОРИГИНАЛЬНОГО ROCKETDOCK 1.3.5:
   - Способ 1: Настройки панели -> вкладка «Общие» -> «Выбрать .ini файл…»
     (выберите, в какую панель импортировать: Панель 1, 2, 3 или Разработка).
   - Способ 2: Правый клик по панели или иконке в трее -> «Импорт RocketDock 1.3.5 (.ini)…».
   - Способ 3: Просто перетащите оригинальный Settings.ini мышкой прямо на панель!
   - Поддерживаются кодировки UTF-16LE, UTF-8 и кириллица Windows-1251.

2. КАК ВКЛЮЧИТЬ 2-Ю, 3-Ю И ПАНЕЛЬ «РАЗРАБОТКА»:
   - Настройки панели -> вкладка «Панели (1–3)» -> отдельные тумблеры ВКЛ/ВЫКЛ
     для Панели 2, Панели 3 и Панели «Разработка» + выбор края экрана.
   - Или через правый клик по панели (ПКМ) / иконку в системном трее:
     * Панель 2 (Справа)
     * Панель 3 (Сверху)
     * Панель «Разработка» (Слева)

3. ПАНЕЛЬ «РАЗРАБОТКА» (ПЕРЕХВАТ АРХИВОВ С GITHUB):
   - Откройте Настройки -> «Разработка» (или нажмите фиолетовую иконку </> на левой панели).
   - Нажмите «Добавить правило» и введите начало имени архива (например: MyApp-win).
   - Когда вы скачиваете архив (.zip / .7z / .tar.gz / .rar) в папку Загрузки (Downloads):
     1) AeroDock перехватывает завершённую загрузку;
     2) Создаёт папку DevApps\<ИмяПрограммы>, распаковывает архив, находит главный .exe
        и добавляет значок с HD-иконкой 128×128 на панель «Разработка»;
     3) При скачивании новой версии: сохраняет копию старой версии в DevApps\_backups\,
        распаковывает новую поверх старой и автоматически переносит файлы настроек
        (.ini, .json, .cfg, .conf, .xml, .yaml, .db, .sqlite, .env и ваши файлы);
     4) Через ПКМ по значку программы доступен откат к прошлой версии в 1 клик!

ГОРЯЧИЕ КЛАВИШИ:
- Ctrl + Alt + R — полностью скрыть / показать все панели (с остановкой опроса).
- Ctrl + перетаскивание — переместить или удалить значок при включённой блокировке.
- Ctrl + Alt + Shift при сворачивании окна — навсегда исключить окно из дока.
- Ctrl при сворачивании окна — однократно свернуть в панель задач Windows.

ЗАПУСК:
Просто запустите aerodock.exe из любой папки или с USB-флешки.
Для ручного запуска отдельной панели: aerodock.exe --dock=2, --dock=3 или --dock=4.
