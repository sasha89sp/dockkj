============================================================
AeroDock Portable v3.0 для Windows (Flutter + Native Win32)
============================================================

Полностью портативный аналог RocketDock с поддержкой 1–3 независимых панелей!
Все настройки хранятся в Settings.ini рядом с aerodock.exe (можно запускать с флешки).

ОСНОВНЫЕ ВОЗМОЖНОСТИ:
- 1, 2 или 3 независимые панели одновременно (Multi-Dock): у каждой свой край экрана,
  монитор, скин, размер значков и набор ярлыков.
- Нативный Win32 FFI (0% нагрузки в простое, мгновенный отклик без зависаний).
- Сворачивание окон Windows прямо в док с живым превью при наведении (PrintWindow/Aero).
  * Ctrl+Alt+Shift при сворачивании — навсегда исключить окно из дока.
  * Ctrl при сворачивании — однократно свернуть в панель задач.
- Индикаторы запущенных программ + переход к уже открытому окну (Open Running).
- Drag-n-Drop на иконки:
  * файл на программу (.exe) — открывает файл в ней;
  * файл на папку — копирует файл внутрь папки;
  * файл на Корзину — удаляет файл в Корзину Windows.
- Поддержка всех типов элементов RocketDock:
  File, Path, Blank Icon, Separator, Recycle Bin (2 состояния: пустая/полная),
  Dock Settings, Quit.
- Встроенные доклеты + папка Docklets/ (ObjectDock формат):
  Часы (Clock), Батарея (Battery), CPU/RAM (SysStats), Календарь, Стек-папка.
- Совместимость со скинами RocketDock / ObjectDock / MobyDock / RK Launcher / Y'z Dock:
  просто скопируйте папку скина (с background.ini и PNG) в папку Skins/.
- Настройки иконок: Имя, Target, Start In, Arguments, Run (Обычное/Свёрнутое/Развёрнутое),
  Open Running (Global/Always/Never), Popup Menu, менеджер папок с иконками (+ / −).
- Настройки дока (6 вкладок): General, Icons (Opacity, Zoom Opaque, Zoom Width/Duration),
  Position (включая «Monitor *» — все мониторы как один, и слои Top/Normal/Bottom),
  Style (шрифт, цвет, тень и обводка подписей), Behavior (AutoHide + Popup on Mouseover),
  Defaults (сброс настроек без удаления значков).
- Мультиязычность: копируйте языковые файлы *.ini в папку Languages/.

ГОРЯЧИЕ КЛАВИШИ:
- Ctrl + Alt + R — полностью скрыть / показать все панели (с остановкой отрисовки).
- Ctrl + перетаскивание — переместить или удалить значок при включённой блокировке.

ЗАПУСК:
Просто запустите aerodock.exe из любой папки или с USB-флешки.
Для ручного запуска отдельной панели: aerodock.exe --dock=2 или --dock=3.
