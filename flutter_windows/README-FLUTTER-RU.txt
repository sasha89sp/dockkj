============================================================
AeroDock Portable v3.6 для Windows (Flutter + Native Win32)
============================================================

Полностью портативный аналог RocketDock с поддержкой 1–3 независимых панелей,
панелью «Разработка», живым предпросмотром настроек, автопереносом настроек
при обновлении в новую папку и автоматическим бэкапом!

1. УНИВЕРСАЛЬНЫЙ ИМПОРТ SETTINGS.INI (ROCKETDOCK 1.3.5 И AERODOCK):
   - Способ 1: Настройки панели -> вкладка «Общие» -> «Выбрать .ini файл…»
     (выберите, в какую панель импортировать: Панель 1, 2, 3 или Разработка).
   - Способ 2: Правый клик по панели или иконке в трее -> «Импорт Settings.ini…».
   - Способ 3: Просто перетащите Settings.ini мышкой прямо на панель!
   - Поддерживаются ВСЕ форматы RocketDock 1.3.5 ([RocketDock], [RocketDock\Icons],
     [Software\RocketDock\Icons], [Icons], [Icon0..N], UTF-16LE с/без BOM, UTF-8,
     кириллица Windows-1251), а также файлы Settings.ini от AeroDock.

2. ЖИВОЙ ПРЕДПРОСМОТР НАСТРОЕК БЕЗ СКРЫТИЯ ПАНЕЛЕЙ И ИКОНОК:
   - Окно настроек открывается отдельно поверх экрана — все панели остаются видны!
   - Двигайте ползунки размера, отступа, позиции, прозрачности или переключайте край
     экрана (Снизу / Сверху / Слева / Справа) и наблюдайте изменения в реальном времени.
   - Кнопка «Отмена» откатывает все изменения назад; «Сохранить» закрепляет их.
   - Исправлена работа с масштабом Windows (125% / 150% / 200% DPI) и добавлено
     автомасштабирование: значки больше никогда не обрезаются и не скрываются.

3. ОБНОВЛЕНИЕ БЕЗ ПОТЕРИ НАСТРОЕК + АВТОМАТИЧЕСКИЙ БЭКАП:
   - Распакуйте новую версию в новую папку и запустите aerodock.exe — ваши настройки,
     все 4 панели, правила «Разработки» и пользовательские иконки автоматически
     перенесутся из локального зеркала профиля Windows (%LOCALAPPDATA%\AeroDockPortable\ProfileSync).
   - Распаковка поверх старой папки также безопасна: архив больше не перезаписывает
     ваш Settings.ini!
   - В Настройках -> «Бэкап и сброс» настраивается автобэкап (при запуске / раз в день /
     раз в неделю), кнопка «Создать бэкап сейчас» и восстановление любого бэкапа в 1 клик.

4. ПАНЕЛЬ «РАЗРАБОТКА» (ПЕРЕХВАТ АРХИВОВ С GITHUB):
   - Откройте Настройки -> «Разработка» (или нажмите фиолетовую иконку </> на левой панели).
   - Добавьте правило с началом имени архива (например: MyApp-win).
   - При скачивании архива (.zip / .7z / .tar.gz / .rar) в Загрузки (Downloads):
     * создаётся папка DevApps\<Имя>, архив распаковывается и добавляется значок;
     * при скачивании новой версии старая сохраняется в DevApps\_backups\, новая
       распаковывается поверх, а файлы настроек (.ini, .json, .cfg, .db и др.) переносятся;
     * через ПКМ по значку доступен откат к прошлой версии в 1 клик!

ГОРЯЧИЕ КЛАВИШИ:
- Ctrl + Alt + R — полностью скрыть / показать все панели.
- Ctrl + перетаскивание — переместить или удалить значок при включённой блокировке.
- Ctrl + Alt + Shift при сворачивании окна — навсегда исключить окно из дока.
- Ctrl при сворачивании окна — однократно свернуть в панель задач Windows.

ЗАПУСК:
Просто запустите aerodock.exe из любой папки или с USB-флешки.
Для ручного запуска: aerodock.exe --dock=2, --dock=3, --dock=4 или --settings.
